# Three-minute judging demo

**0:00–0:30** Open BioTwin and select **Start simulation**. Show the Type 1 diabetes case and open the profile editor to point out the difference between model inputs and context. Exit with Escape.

**0:30–1:00** Select **Heart**. Orbit, zoom, click a structure and isolate it. Show how the camera and anchored selection follow the real anatomy. Return to full view if desired.

**1:00–1:55** Open **Compare** and choose **Create matched twin**. Both workers start at 00:00. Choose **Configure B**, select a virtual infusion setting, confirm, and run five minutes. View the B − A glucose difference. Switch between glucose and potassium to inspect the actual traces.

**1:55–2:30** Scrub to time zero on the ruler and switch A/B at the same timestamp. Return live and choose **What changed?**. In **Timeline**, open **Long-term outlook** and explain the missing inputs and separate cardiovascular endpoint.

**2:30–3:00** Open **Reports** and show the actual action and event histories in the downloadable JSON or the print report. Save the session locally for later replay.
